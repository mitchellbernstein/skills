# Skills

Reusable skills for coding agents.

## Available Skills

- `setup-xai-twilio-cloudflare-sip`: Set up and debug an xAI Voice Agent phone number using Twilio Elastic SIP Trunking, with optional Cloudflare Workers webhook handling.

## Structure

Each skill lives in its own folder with a `SKILL.md` file:

```text
skill-name/
└── SKILL.md
```

Copy a skill folder into your agent's skills directory or package it with whatever skill distribution system you use.
